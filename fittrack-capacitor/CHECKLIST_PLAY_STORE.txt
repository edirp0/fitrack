━━━ FASE 1: INSTALLAZIONI PC ━━━━━━━━━━━━━━━━━━━━━━━━━━━

[ ] Node.js 18+ installato
    → https://nodejs.org (scarica LTS)
    → Verifica: node --version

[ ] Android Studio installato
    → https://developer.android.com/studio
    → Durante setup seleziona: Android SDK + AVD + HAXM

[ ] Android SDK 34 installato
    → Android Studio → SDK Manager → Android 14 (API 34)

[ ] Variabile ANDROID_HOME impostata
    Windows: Pannello controllo → Variabili d'ambiente
    → ANDROID_HOME = C:\Users\NOME\AppData\Local\Android\Sdk
    → PATH aggiungi: %ANDROID_HOME%\platform-tools

━━━ NOTE IMPORTANTI ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

• Il file keystore.jks è IRRECUPERABILE se perso.
  Salvalo su Google Drive, USB e cloud.
  Senza di esso non puoi mai aggiornare l'app.

• Ogni aggiornamento: aumenta versionCode in build.gradle
  (es. 1 → 2 → 3) e versionName (es. "1.0.0" → "1.1.0")

• Dopo ogni modifica a index.html:
  npx cap sync → poi ribuilld da Android Studio

• Per testare velocemente senza rebuil APK:
  npx cap run android  (se telefono collegato via USB)
